# Artwork slots

Drop SVG files here and point `art_left` / `art_right` at them.

They ship empty deliberately. Organisation emblems — scouting marks among
them — are registered trademarks. Using one on your own plaque is your call;
baking it into a model that anyone can download and regenerate is
redistributing someone else's mark, so any published version leaves these
blank.

SVG needs closed paths (no open strokes) or OpenSCAD imports nothing.
